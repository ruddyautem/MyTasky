# Vue 3 + TypeScript + Vite

Ce modèle vous aide à démarrer le développement avec Vue 3 et TypeScript dans Vite. Le projet utilise les composants SFC de Vue 3 avec `<script setup>`. Consultez la documentation sur [script setup](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) pour en savoir plus.

Pour en savoir plus sur la configuration recommandée du projet et le support IDE, consultez le [guide TypeScript des docs Vue](https://vuejs.org/guide/typescript/overview.html#project-setup).
